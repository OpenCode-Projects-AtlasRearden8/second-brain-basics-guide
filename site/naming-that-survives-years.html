Naming That Survives Years

File names are the cheapest database you will ever own. A good name is a
search bar that works even when the power is out.

Your future self meets your files through three doors: the eye (different
systems), search (typing what it might be called), and history
(browsing a folder a year later). A survival-tested name serves all three.
Here are the rules — few, boring, and they work.

The rules

1. Name for search, not for looks

Write the words you would actually type when looking for it. "Pharmacy
receipt March" beats "receipts_final_v2" (which loses to "receipts_march" in a fair fight,
every time).

2. Dates, when dates matter, in ISO order

2026-03-14 — year first, always. It sorts correctly forever. No other
format does. Use dates on:

  • daily notes (2026-03-14.md)
  • projects (2026-04-dissertation.md)
  • anything financial, medical, or legal (which is also "anything, later")

3. Prefixes when sequence matters

Numbers sort before letters, so use prefixes to keep related files in
reading order:

2026-10-client-handbook/
  01-outline.md
  02-draft.md
  03-feedback.md

4. Boring beats clever

protein-notes.md will still be findable in 2031. 🧠💪 gains.md will be a
mystery. Emojis, code names, and jokes age like milk. Save them for the
contents — names should be the label on the outside of the box.

5. One idea, one name, few words

Aim for 2–5 words. If the name runs long, the file is probably two files or
the idea is not clear yet — either is fine, just say so in the name:
idea-unsynced-handoffs.md.

Two naming fields to know

These recur across the manual and the [[glossary]]:

  • YYYY-MM-DD — the date pattern for anything time-bound: 2026-03-14.md.
  • type-topic-slice — the pattern for idea notes: a type word

(idea-, ref-, howto-), then the topic, optionally a narrow slice.
Example: ref-markdown-tables.md.

You do not need both everywhere. Pick the pattern that matches the file's
job: time-bound files get dates; timeless notes get the type/topic pair.

Do this now (3 minutes)

Look at today's folder (or your downloads folder — braver). Rename one
file with the date-first rule. That is the habit: one rename a day shrinks
the mystery pile without ever feeling like a chore.
