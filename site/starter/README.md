# My Second Brain

A starter vault for the plain-file personal knowledge base from the
*Second Brain Basics* manual. Everything here is plain Markdown — open any
file in any editor, today or in ten years.

## The corners and extras

| Folder        | What lives there |
| ------------- | ---------------- |
| `00-inbox/`   | Fleeting notes — raw thoughts, one per file. Allowed to be messy. |
| `10-projects/`| Active projects, five or six max; next action bolded at the top. |
| `20-archive/` | Anything finished or cold, organized by year. |
| `50-hubs/`    | Optional index pages that collect `[[wiki-links]]` per life area. |
| `90-daily/`   | Today's landing pad — one file per day, catches everything. |
| `templates/`  | Blank starting text for each entry type. Copy, paste, go. |

The manual chapters in `docs/` are the full reference for each corner. This
README is just the cheat sheet.

## Daily rhythm (small by design)

1. Open today's file in `90-daily/` (name it `YYYY-MM-DD.md`).
2. Anything that lands in your head, drop it there. No sorting required.
3. Once a month, spend 15 minutes on the tidy chapter. Timer on; done is
   done.

## Making this vault yours

Copy this whole folder somewhere comfortable and rename it —
`my-second-brain/` or any name you like. The files do not know their own
path, so nothing breaks. Keep one editor's worth of habits; switching
editors later costs nothing because it is all plain text.

## An example is included

`90-daily/2026-10-27.md` and `00-inbox/idea-one-paragraph-a-day.md` are
filled-in examples showing the tone and shape. Read them, then delete or
archive them once you have real days of your own. (Examples are training
wheels, not decoration.)
