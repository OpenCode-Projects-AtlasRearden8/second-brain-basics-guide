Free Editors: Where to Write

The best editor is the one already open on your machine. Everything below
is free, local-first, and good enough to last years.

You only need one thing: an app that opens .md and .txt files fast and
does not get in the way. Here are free options matched to situations, from
"lowest effort" to "most set-up." All of them work fine with the vault
folder this manual gives you.

Tier 0: What is already on your machine

Your vault is plain files, so plain text tools already qualify:

  • Windows: Notepad (yes, really) or Notepad++ for a nicer experience.
  • macOS: TextEdit (set it to plain text in preferences) or the free

TextMate/CotEditor route.

  • Linux: gedit, Kate, or nano in the terminal.
  • Phone: any notes app that can open files, or nothing at all — phones

can be capture-only, and the vault sorts at the desk.

This tier is perfectly legitimate. "No fancy apps required" is not a
compromise; it is a feature. If you never leave Tier 0, your system still
works completely.

Tier 1: Markdown editors (free, local files)

Same files, nicer view: headings hierarchy, clickable links, live word
counts. Good once you write daily and want comfort.

  • VS Code (Windows/macOS/Linux) — free, extremely common, opens a whole

folder so your vault feels like a dashboard. Install the "Markdown All in
One" extension for [[wiki-link]] autocompletion comfort.

  • Zettlr (Windows/macOS/Linux) — built exactly for academic-style

Markdown with a sidebar of your vault and first-class [[wiki-link]]
support.

  • Obsidian (Windows/macOS/Linux, free for personal use) — the friendliest

GUI for wiki-links, backlinks, and graphs. Local files only; it edits your
vault folder directly, so you are never locked in even though it feels
like an app.

For the setup in this manual, Zettlr or Obsidian are the sweet spots:
they treat your folder as plain Markdown (so Tier 0 always still works) and
they make [[linking-ideas]] feel effortless.

Tier 2: Syncing across devices (free routes)

Local-first means your files live on your machine first. Syncing is then
just "make copies reach my other devices," and there are free, boring ways:

  • A folder in a sync service (one that syncs a normal folder) — the

vault is just files, so any file-syncing folder works.

  • Git — if you are comfortable with it, a private repo on any host is

free versioned backup. Never made public unless you choose to.

  • USB/e-mail-to-self — genuinely. For a daily file of a few kilobytes,

this is not silly, it is auditing-light.

One warning that applies to every tool: some apps use "their" file types
(.otl, proprietary databases). If an app cannot show your notes as
.md/.txt in Finder/File Explorer, it is not local-first. Skip it.

Choosing in ten seconds

  • Hate installing things? Notepad/TextEdit. Done. Truly.
  • Want a little polish? Zettlr or Obsidian, mentioned above.
  • Already using VS Code for coding or anything else? Open your

vault in it. Zero new tools.

Do this now (5 minutes)

Open your vault folder in the editor you will actually use. Type one
sentence in today's daily file so the app is "warmed" as yours.
Tomorrow's you will find the file faster because it is no longer the first
time.
